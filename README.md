# Sistema de Gestión de Pedidos - Food Store 🍔🛒

Trabajo Práctico Integrador desarrollado en Java para la Tecnicatura Universitaria en Programación. El sistema consiste en una aplicación de consola interactiva que permite administrar el flujo completo de un e-commerce gastronómico (Categorías, Productos, Usuarios y Pedidos) aplicando los pilares de la Programación Orientada a Objetos (POO).

# Modo de uso
- Utilizar numeros para acceder al menu/opcion seleccionada.
- Recordar que cero (0) funciona como boton 'atras' y corta ejecucion.

## 🚀 Instrucciones de Ejecución (Visual Studio Code / NetBeans)
1. Localizar archivo Main.java en directorio src/integrado/prog2.
2. Click derecho y seleccionar la opcion 'run java'.

## Aclaracion importante:
- Dadas las restricciones de tiempo y desarrollo, el presente programa presenta la UI con menus accesibles, y creacion de objetos, SALVO las clases Usuario y Pedido/DetallePedido.
